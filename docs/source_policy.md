# Source policy

Use only sources you are allowed to access and cite. Never bypass logins, paywalls, quote forms, or anti-scraping controls.

## Accepted evidence

- public product page
- public store listing
- public datasheet / SDS / TDS
- public OEM material catalog
- user-owned manual quote summary

## Not allowed

- confidential quote PDFs uploaded publicly
- scraped login-only stores
- guessed prices with no evidence
- average prices with mixed package sizes and missing quantities

## Staleness

Prices should be rechecked. A row can stay in the seed file, but the `source_accessed_date` and `confidence` should show freshness and uncertainty.

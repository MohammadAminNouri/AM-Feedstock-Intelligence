# Material taxonomy

## Metals

- Fe: 316L, 17-4PH, H13, maraging steel, tool steels
- Ni: IN718, IN625, HX, C-276, Haynes alloys
- Ti: CP-Ti, Ti-6Al-4V, Ti-6Al-4V ELI, TiAl
- Al: AlSi10Mg, AlSi7Mg, AlSi12, Scalmalloy, 6061/7075 candidates
- CoCr: CoCrMo, CoCrW
- Cu: Cu, CuCrZr, GRCop-42, GRCop-84
- Refractory: W, Mo, Ta, Nb, W-Re

## Polymers

- Powder: PA12, PA11, TPU, PP, PEKK, PEEK
- Filament: PLA, PETG, ABS, ASA, TPU, PC, PA6, PA12, PPS, PEI, PEEK, PEKK
- Composite filament: PA-CF, PET-CF, PETG-CF, ASA-CF, PPS-CF, PA-GF, ESD grades
- Resin: standard, tough, durable, flexible, dental, castable, biocompatible, ceramic-filled
- Pellets: virgin, recycled, fiber-filled, flame-retardant, large-format materials

## Ceramics

Alumina, zirconia, silica, silicon carbide, silicon nitride, hydroxyapatite, ceramic-loaded resins/slurries.

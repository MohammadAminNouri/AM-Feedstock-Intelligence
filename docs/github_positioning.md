# GitHub positioning

## Strong one-liner

Open AM feedstock intelligence: metals, polymers, powders, filaments, resins, real public prices, suppliers, process suitability, reuse risk, and trend signals.

## Why people may star it

- It solves a real pain: nobody knows what AM materials actually cost.
- It includes polymers and filaments, not only expensive metal powders.
- It separates manufacturer, reseller, marketplace, and quote-only products.
- It is useful for both research and procurement.
- It has a dashboard and scripts, not just a static table.
- It can become an ML dataset later.

# Roadmap

## v0.1 - Seed catalog

- Metal powder seed records
- Polymer powder seed records
- Filament/resin/pellet/wire/slurry categories
- Streamlit dashboard
- Cost models
- Source confidence rules

## v0.2 - Datasheet extraction

- Detect missing PSD, diameter, density, flow, drying, and safety fields
- Add datasheet URL field
- Add SDS/TDS completeness checklist

## v0.3 - Supplier intelligence

- Separate atomizers, OEMs, manufacturers, resellers, marketplaces
- Add geography and MOQ fields
- Add lead-time observations

## v0.4 - Price intelligence

- Currency conversion module
- Price history plots
- Manual quote privacy workflow
- Regional price comparisons

## v0.5 - ML layer

- Price-band prediction
- Process suitability classification
- Missing-field recommendation
- Feedstock knowledge graph

## v1.0 - Serious open database

- 500+ verified feedstock records
- 100+ suppliers
- dashboards for metals, polymers, resins, filaments
- clear contribution workflow
